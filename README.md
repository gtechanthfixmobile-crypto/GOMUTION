# GOMUTION

**Global Student & Inventor Project Stream**

GOMUTION is a lightweight, social-style web platform where students, makers, and inventors around the world can share their projects, ideas, prototypes, demonstration videos, images, and written build notes with automatic date and day stamping.

---

## Overview

Built for speed and simplicity on everyday devices, GOMUTION gives creators a dedicated space to document what they build and explore without heavy bloat. Users can browse incoming projects, filter by engineering or study field, sort by recency or applause, and share their own work in a clear, structured feed.

---

## Key Features

- **Project & Idea Feed:** A responsive stream where creators post project titles, engineering categories, written explanations, images, and demonstration videos alongside automatic day and date stamps.
- **Lightweight Text-Payload Architecture:** Converts project data and media into compact text representations so synchronization stays fast and lightweight across devices.
- **Strict Project Media Rules:**
  - **3-to-20 Minute Video Window:** Validates video length before posting so clips stay focused on project demonstrations (between 3 and 20 minutes) rather than full-length movies.
  - **Anti-Movie & Piracy Filter:** Screens file names for commercial movie, series, and rip patterns to keep the feed focused on original student and inventor work.
  - **Image Optimization:** Compresses uploaded images on the client side for smooth loading and lower bandwidth usage.
- **Smooth Playback & Discovery:** Automatically pauses off-screen videos during scrolling to save memory and performance, paired with live search, category filtering, and sorting.

---

## What Users Can Share

- **Videos:** Project walk-throughs, working prototypes, experiments, and live build demos (3 to 20 minutes).
- **Images:** Circuit layouts, sketches, hardware builds, UI screenshots, and diagrams.
- **Explanations & Notes:** Step-by-step descriptions of how an idea works, materials or tools used, and lessons learned.
- **Day & Date Stamps:** Clear posting dates and days so progress and updates are easy to follow.

---

## Tech Stack

- **Frontend:** HTML5, CSS3, and Vanilla JavaScript
- **Cloud & Backend:** Firebase Authentication and Firebase Realtime Database
